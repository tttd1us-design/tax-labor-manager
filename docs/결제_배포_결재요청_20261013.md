| 옵션 | PG사 | 계좌개설비 | 수수료 | 추천 이유 |
|------|------|-----------|--------|----------|
| A (추천) | 토스 | 0원 | 2.75% | 계좌개설비 없음, 수수료 최저, 개발자 친화적 |
| B | KCP | 500만 원 | 추후 협의 | 전통적 신뢰도, 높은 장벽 |
| C | KG | 200만 원 | 추후 협의 | 중간 장벽 |
| D | 보류 | — | — | 결제 모듈 설계만 유지, Free 등급만 운영 |

### 2. GitHub Pages 배포 승인
정적 파일(단일 index.html, 47KB)의 무료 배포를 요청합니다.
- 비용: 0원 (GitHub Pages Free, Public 리포지토리)
- 스파크 리뷰(S-1013)에서 "GitHub Pages 배포" 조건부 승인
- 배포 후 검증 체크리스트 포함 (접속, 알림, 계산기, 일정, 면책고지, ICS 내보내기)

| 옵션 | 설명 | 추천 여부 |
|------|------|----------|
| A (추천) | 승인 — GitHub Pages에 배포 (무료, 정적 파일) | ✅ |
| B | 보류 — 현재 설계 단계에서 멈춤 | ❌ |
