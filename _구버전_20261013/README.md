# 세무 일정 관리 + 세금 계산기 앱

## 개요
이 앱은 세무 일정 관리, 세금 계산기, 브라우저 알림 기능을 제공하는 정적 HTML/CSS/JS 단일 파일 애플리케이션입니다.
- 로컬스토리지를 기반으로 일정을 저장하고 관리합니다.
- 2026년 세율을 적용하여 세금을 계산합니다.
- 브라우저 알림 기능을 통해 중요한 일정을 알립니다.

## 파일 구조
- `index.html`: 메인 HTML 파일
- `style.css`: 스타일 시트
- `script.js`: 애플리케이션 로직
- `README.md`: 이 파일

## 설치 및 실행 방법
1. 저장소 또는 다운로드 받은 폴더를 로컬에 클론하거나 다운로드합니다.
2. `index.html` 파일을 더블 클릭하거나 웹 브라우저에서 열어 실행합니다.
   - 예를 들어, Chrome, Firefox, Edge 등 현대 브라우저에서 작동합니다.
3. 별도의 서버 설정이 필요하지 않습니다 (정적 파일만 사용).

## 사용 방법
### 세무 일정 관리
1. 날짜 입력 필드에 날짜를 선택합니다 (YYYY-MM-DD 형식).
2. 일정 제목 입력 필드에 일정 내용을 입력합니다.
3. "추가" 버튼을 클릭하면 일정이 리스트에 추가됩니다.
4. 추가된 일정은 페이지 새로고침 후에도 로컬스토리지에 저장되어 유지됩니다.
5. 일정 옆에 있는 "삭제" 버튼을 클릭하면 해당 일정을 삭제할 수 있습니다.

### 세금 계산기
1. 소득액 입력 필드에 과세 대상 소득액을 입력합니다 (예: 5000000).
2. 세율 입력 필드에 적용할 세율을 입력합니다 (기본값: 6%). 2026년 세율에 맞게 조정할 수 있습니다.
3. "세금 계산" 버튼을 클릭하면 계산된 세금과 납부 예상액이 표시됩니다.

### 알림 기능
1. "알림 권한 요청" 버튼을 클릭하여 브라우저 알림 권한을 허용합니다.
2. "테스트 알림 발송" 버튼을 클릭하면 테스트 알림이 표시됩니다.
   - 실제 알림 기능은 일정과 연동하여 확장할 수 있습니다 (현재는 테스트용).

## 기술 스택
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- 브라우저 로컬스토리지 (일정 저장)
- 브라우저 Notification API (알림)

## 주의 사항
- 이 앱은 클라이언트 측에서만 실행되며, 서버 측 처리나 데이터베이스가 없습니다.
- 로컬스토리지는 해당 브라우저와 기기에서만 유지됩니다. 다른 기기나 브라우저에서는 공유되지 않습니다.
- 알림 기능을 사용하려면 브라우저 알림 권한을 반드시 허용해야 합니다.
- 결제 연동은 별도 승인이 필요하므로 현재 구현되지 않았습니다.
