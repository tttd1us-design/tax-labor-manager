## 4. 사용 방법

### 세무 일정 보기
- 화면에 표시되는 기본 세무 일정(32건) 확인
- "일정 추가" 탭에서 직접 일정 입력 → 브라우저 저장

### 세금 계산
- "세금 계산기" 탭에서 계산 항목 선택
- 금액 입력 → "계산" 버튼 클릭 → 결과 확인
- 모든 결과에는 법적 면책 고지가 표시됨

### 알림 받기
- "알림 설정" 탭 → "알림 권한 요청" 클릭
- 브라우저에서 알림 허용 선택
- 신고 기한이 임박하면 자동으로 알림 표시

### 캘린더 내보내기
- "알림 설정" 탭 → "캘린더 다운로드(.ics)" 클릭
- 파일을 메일로 전송하거나 스마트폰 캘린더에 가져오기
